## 📂 Projetos em Destaque

### ❄️ WinterFX

Framework desenvolvido para simplificar e estruturar o desenvolvimento de aplicações JavaFX.

O projeto busca fornecer recursos como gerenciamento de views, recursos, componentes e infraestrutura para aplicações JavaFX, seguindo princípios de modularidade e reutilização.

🔗 [Ver projeto no GitHub](https://github.com/rephaelTAS/WinterFx)

---

### 🎨 sceneGrafic

Designer visual para interfaces **Avalonia/AXAML**, inspirado no conceito do JavaFX Scene Builder.

A proposta é permitir a criação e edição visual de interfaces gráficas através de uma ferramenta própria, gerando e manipulando arquivos `.axaml`.

🔗 [Ver projeto no GitHub](https://github.com/rephaelTAS/sceneGrafic)

---

### 🖥️ Gestão de Equipamentos de TI

Sistema desktop para gerenciamento de equipamentos e recursos de tecnologia da informação.

O projeto envolve gerenciamento de inventário, equipamentos, funcionários, histórico de utilização e outras informações relacionadas à infraestrutura de TI.

🔗 [Ver projeto no GitHub](https://github.com/rephaelTAS/Gestao_Dep_It_V4)
